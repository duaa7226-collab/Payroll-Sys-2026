6. REQUIRED CALCULATION LOGIC
==================================================

The salary engine must always use the ACTIVE rule set from the centralized Rules Control Center and must never rely on hardcoded payroll constants in scattered files.

Support all of the following calculation strategies as editable rule modes:
- days_prorated_mode
- orders_based_mode

The active rule set must decide which mode is used.

------------------------------------------
6A. DAYS-PRORATED MODE
------------------------------------------

Use this when the active salary_divisor_mode = days_prorated_mode.

Formulas:
- Daily Base Rate = Monthly Base Salary / Standard Working Days
- Daily Target Rate = Monthly Target Orders / Standard Working Days
- Adjusted Base Salary = Daily Base Rate * Actual Working Days
- Raw Adjusted Target Orders = Daily Target Rate * Actual Working Days
- Adjusted Target Orders = rounded based on the selected rounding mode
- Extra Orders = max(Completed Orders - Adjusted Target Orders, 0)
- Missing Orders = max(Adjusted Target Orders - Completed Orders, 0)
- Bonus Amount = Extra Orders * Bonus Per Extra Order
- Missing Order Deduction = Missing Orders * Deduction Per Missing Order

Gross Salary Before Other Penalties:
- if Completed Orders >= Adjusted Target Orders:
  Gross Salary Before Other Penalties = Adjusted Base Salary + Bonus Amount
- else:
  Gross Salary Before Other Penalties = Adjusted Base Salary - Missing Order Deduction

------------------------------------------
6B. ORDERS-BASED MODE
------------------------------------------

Use this when the active salary_divisor_mode = orders_based_mode.

Core concept:
- Monthly Base Salary is tied to Monthly Target Orders
- Salary Per Order Rate = Monthly Base Salary / Monthly Target Orders
- Default example: 2000 / 450 = 4.444444444444444 per order
- If a driver scores 231 orders, then Base Salary Equivalent By Orders = 231 * 4.444444444444444

Default formulas:
- Salary Per Order Rate = Monthly Base Salary / Monthly Target Orders
- Daily Target Rate = Monthly Target Orders / Standard Working Days
- Raw Adjusted Target Orders = Daily Target Rate * Actual Working Days
- Adjusted Target Orders = rounded based on selected rounding mode
- Base Salary Equivalent By Orders = Completed Orders * Salary Per Order Rate
- Selected Target Threshold = if Use Actual Working Days = yes then Adjusted Target Orders else Monthly Target Orders
- Extra Orders = max(Completed Orders - Selected Target Threshold, 0)
- Missing Orders = max(Selected Target Threshold - Completed Orders, 0)
- Bonus Amount = Extra Orders * Bonus Per Extra Order
- Missing Order Deduction = Missing Orders * Deduction Per Missing Order

Default gross logic in orders_based_mode:
- Gross Salary Before Other Penalties = Base Salary Equivalent By Orders + Bonus Amount - Missing Order Deduction

Important rule:
- Bonus and deduction remain active in orders-based mode unless the admin disables them from the Rules Control Center

Optional alternative formula policies for admin selection:
- strict_target_salary_policy:
  - if Completed Orders = Selected Target Threshold, salary equals Monthly Base Salary
  - if Completed Orders < Selected Target Threshold, salary = Base Salary Equivalent By Orders - Missing Order Deduction
  - if Completed Orders > Selected Target Threshold, salary = Monthly Base Salary + Bonus Amount

- linear_order_rate_policy:
  - salary = Base Salary Equivalent By Orders + Bonus Amount - Missing Order Deduction

The Rules Control Center must allow the admin to choose which orders-based formula policy is active.

------------------------------------------
6C. COMMON PENALTY LOGIC
------------------------------------------

Total Other Penalties:
- sum of all enabled and mapped penalty values from the workbook according to the active penalty rules

This total may include:
- acceptance penalties
- contact penalties
- stacking deduction
- declined penalties
- late penalty
- no-show penalty
- no-show special cities penalty
- daily acceptance penalty
- missed days penalty
- rider balance deduction
- car deduction
- TGA deduction
- traffic violations / traffic tickets
- manual deductions
- other mapped deductions

Final Net Salary:
- Final Net Salary = Gross Salary Before Other Penalties - Total Other Penalties

Important:
- the engine must normalize negative source deductions correctly and avoid double-sign errors
- the engine must never use fixed values directly inside calculation code if those values belong to business rules
- all such values must come from the centralized rules source
- each payroll run must save a snapshot of the exact applied rules
- later rule changes must not alter historical payroll run outputs
